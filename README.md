# Python Learning Exercises

Private Python practice repository. These **independently written** examples were prepared after reviewing the directory `D:\Dropbox\Work\Learning\Python\Learning Python`.

## Important provenance and licensing note

The Dropbox folder principally contains exercise files for **Joe Marini's LinkedIn Learning course _Learning Python_**. The upstream exercise package is accompanied by the LinkedIn Learning Exercise Files License Agreement (© 2021 LinkedIn Corporation). Those original training files, starter/finished solutions, datasets, and the course package have **not been copied into this repository**.

## Contents
- `exercises/basics.py` — functions, loops, conditions and simple validation
- `exercises/dates_times.py` — calendar dates and timedeltas
- `exercises/file_operations.py` — safe local text-file processing
- `exercises/internet_formats.py` — parsing JSON and XML without network access

## Run

Requires Python 3.10+; no external dependencies.

```bash
python exercises/basics.py
python exercises/dates_times.py
python exercises/file_operations.py
python exercises/internet_formats.py
```

Run examples in a disposable working directory where appropriate. Scripts have not been execution-tested during this migration.

Original Dropbox files remain unchanged.
